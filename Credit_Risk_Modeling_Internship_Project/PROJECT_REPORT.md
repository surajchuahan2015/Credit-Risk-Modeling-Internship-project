# Internship Project Report — Credit Risk Modeling

## 1. Objective
Predict loan default risk using data analytics, SQL and machine learning.

## 2. Data Preparation
Checked missing values, data types and categorical variables. Numerical variables were imputed/scaled and categorical variables were one-hot encoded.

## 3. EDA
Analyzed default distribution, credit score, income, loan amount and debt-to-income ratio.

## 4. SQL Analysis
Used SQLite queries for filtering, grouping, aggregation and default-rate analysis.

## 5. Machine Learning
Compared Logistic Regression and Random Forest classifiers.

## 6. Evaluation
Reported Accuracy, Precision, Recall and ROC-AUC. Because credit-risk datasets can be imbalanced, Recall and ROC-AUC should be considered along with accuracy.

## 7. Deliverables
- Python analysis script
- SQL query file
- Dataset
- EDA charts
- Model comparison CSV/chart
- Saved Random Forest model
- README documentation
